# 架构生长实验室

以虚构的「青屿小店」为线索，从单台服务器逐步走到 Kubernetes。课程包含 15 个阶段、60 个基础学习页面、56 节专题讲义、68 个请求步骤和 45 个情景演示。第一阶段还可以调节每秒请求数，逐秒观察任务积压与消退。

## 打开课程

按项目 README 启动预览，访问 <http://127.0.0.1:8765/architecture/>。学习进度保存在当前浏览器。

## 逐页学习

每个阶段包括四个基础页面与一个独立专题课。专题课围绕具体业务故障展开，复杂章节分为多节；底部按钮依序推进全部小节后进入下一阶段。

- 业务与架构展示业务规模、现场问题、架构、部署配置、情景实验和完整组件清单。部署配置可逐项展开，也可在架构图的组件说明中查看。
- 各阶段的月费用可在 AWS 和阿里云新加坡间切换，以美元估算 30 天。可调整日访问量、各组服务器台数、单图传输大小和 CDN 命中率，并恢复该阶段的默认值。点开各项可查看用量、单价、算式及官方来源。
- 跟着请求走提供自动播放、暂停和逐步查看，可以点击组件检查输入与输出。
- 改造与代价解释变化、维护成本、引入时机和项目部署结构。
- 自测与资料提供答题解释、企业案例、资料链接和“已学懂”标记。
- 专题课从单机内的实际工作展开，到瓶颈诊断、组件原理、选型、故障和改造后的往返流程。Kubernetes 分为七节，分别解释包含层级、管理过程、服务发现、入口方案、路由资源、边车和选型。

完整系统图在第 15 阶段。成长规模与实验容量为教学假设，不能作为生产容量门槛。课程是概念模拟，真实部署还需要配置、测试和恢复演练。

## 继续维护

`course.js` 保存中文讲义、组件解释、步骤与来源。`deployment.js` 记录逐阶段变更的示例配置。`costs.js` 保存用量假设与 2026-11-11 核对的 AWS 与阿里云单价，并从部署配置计算月费用。`app.js` 负责页面与互动，`styles.css` 管理布局与动画。后续可以逐阶段加深讲义和练习。

资料于 2026-11-11 对照官方来源核对。持续更新文档与带日期的公开案例分别标注，后续更新需要再次核对。

## 专题讲义与离线版本

`one-server-seminar.js` 保存第一阶段长篇，`handbook/02-*.js` 至 `15-*.js` 保存其余阶段，`handbook.js` 负责目录与分页。地址中的 `#阶段ID/seminar/页码` 可直接定位小节。

运行 `node tools/architecture/export-handbook.cjs` 从项目根目录更新 `public/architecture/blog/` 下的十五篇独立 HTML 与目录；样式和图包含在文件内，可离线阅读及使用浏览器打印。

2026-11-11 验证：所有 JavaScript 语法通过；浏览器逐页检查新增 55 页在窄屏无横向溢出；检查分页、刷新定位、跨阶段跳转，及阿里云费用台数调整与默认恢复。教学耗时不是实测结果，课程改动不代表重新取得云厂商报价。
